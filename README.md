# ダイスカルテ

ダイスとスキルカードを組み合わせて、ハイスコアを目指すゲームです。GitHub Pages で公開できます。

## 遊び方

- **ソロプレイ**は、カード1枚とダイス1個から始まります。目標スコア以上の結果を出すと、新しいスキルカードと新しいダイスを1つずつ入手します。目標は解放のたびに変わり、図鑑がすべて埋まるとソロクリアです。
- 編成はカード10枚、ダイス10個までです。同じカードや同じダイスは入れられません。
- 1回の挑戦は8ターンです。ダイスは編成の上から順に出て、数が足りなければ先頭に戻ります。カードはシャッフルして引き、使ったカードはその挑戦では戻りません。
- 得点は（出目＋加算）×倍率×コンボ倍率＋追加点です。同じ紋が2連続すると×1.6、以降1段ごとに＋0.6されます。
- **ランキング**は、ソロで解放したカードとダイスだけで遊びます。ニックネームとスコアがオンラインのランキングに保存されます。同じニックネームは、より高いスコアだけが残ります。ランキングでは解放は増えません。

## GitHub Pages

リポジトリの Settings → Pages で、Branch を `main`、Folder を `/ (root)` にして保存してください。公開URLは `https://<ユーザー名>.github.io/<リポジトリ名>/` です。

## カードとダイスを追加する

`js/catalog.js` の `CARDS` と `DICE` の末尾に足します。並びが解放順です。`id` は重複できません。新しい効果は `js/engine.js` の `applyEffect` に処理を追加します。目標スコアとクリア判定は配列の長さから計算されるので、追加した分は未解放のまま既存のセーブに足されます。
